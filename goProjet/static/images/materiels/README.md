# Icônes de matériel

## Ajouter une icône

1. Nommer le fichier : `nom-du-type.extension`
   - Minuscules, tirets à la place des espaces.
   - Ex. : `pelle-chenilles-godet.jpg`, `niveleuse-cat.avif`.

2. Formats acceptés : `.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`, `.avif`, `.gif`.

3. Taille recommandée : carrée, 256×256 px minimum, < 100 Ko.

4. Copier le fichier dans ce dossier.

5. `git add`, `git commit`, `git push`.

6. Railway redéploie automatiquement → l'icône est disponible.

## Fichiers actuels

- `autobeton.jpg` — Autobétonnière
- `bobcat-cat.jpg` — Bobcat
- ...
- `default.avif` — Icône par défaut (fallback)
